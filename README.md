# ia-riwi

Repositorio de actividades prácticas del módulo de Inteligencia Artificial.

## Contenido del repositorio

1. **Ejercicio 1 (`./sesion1`)**
   - **Descripción:** Algoritmo para ordenar correctamente tres números de mayor a menor (o viceversa), contemplando casos donde existan números iguales.

2. **Ejercicio 2 (`./sesion2`)**
   - **Descripción:** Archivo generado en la actividad práctica sobre el caso de estudio para la selección de estudiantes en el programa de apoyo[cite: 1, 2].

3. **Ejercicio 3 (`./sesion3`)**
   - **Descripción:** Desarrollo de la página web funcional para el proyecto *Picaroni*, incluyendo el *prompt* utilizado para su creación[cite: 1, 2].
